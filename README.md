# ADB WiFi Toggle

横向 3×2 安卓桌面小组件：三个开关分别控制**开发者模式**、**USB 调试**、**无线调试**（ADB over WiFi），底部显示守护状态、IP、端口与 WiFi 名称。单 APK 自部署脚本，无前台服务、无开机自启。

## 功能

- **开发者模式**（左侧大开关）：关 = 同时关闭 USB 与无线调试并停守护；开 = 恢复开发者模式与 USB 调试，无线调试保持关闭。
- **USB 调试**（右侧小开关）：单独开关 `adb_enabled`。
- **无线调试**（右侧小开关）：开 = 置 `adb_wifi_enabled=1` 并启动保活守护；关 = 置 0 并停守护。
- **信息区**（2×2）：守护 / IP / 端口 / WiFi 名称，点击整块可刷新。
- 点击开关**先即时翻转**，再按 root 查询到的真实状态纠正。

## 前提

- 已 Root（Magisk，需保留交互式 `su`）。
- 系统「开发者选项 → 无线调试」可用。
- 首次点击时 Magisk 会弹授权，选允许并记住。

## 安装

1. 从 [Releases](https://github.com/cs445194891/adb-wifi-widget/releases) 下载 `adb-wifi-widget-debug.apk` 并安装。
2. 桌面长按 → 添加小组件 → ADB WiFi Toggle，拖到桌面（占 3 格宽 × 2 格高）。

## 说明

- **无自启、运行期保活**：守护仅随无线调试开启而运行，每 30 秒检查并把 `adb_wifi_enabled` 拉回 1。
- **卸载即清理**：脚本、flag、日志都在 App 私有目录，卸载后系统自动删除；守护检测到自身文件消失立即退出，不留 `/data/adb` 残留。
- **更新需先卸载**：debug 签名每次构建不同，`adb install -r` 会失败；卸载会清除脚本与桌面组件实例，重装后需重新添加。
- **状态非实时**：从系统设置改动后，点一下信息区刷新。

## 卸载

`adb uninstall com.adbwifitoggle`，或在桌面长按图标 → 卸载 / 系统设置 → 应用 → 卸载。
